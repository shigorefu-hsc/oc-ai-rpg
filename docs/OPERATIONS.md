# Запуск и обслуживание

## Локально

Нужны Node.js 22.12+ и npm. Из корня репозитория:

    npm ci
    npm run dev

Откройте http://127.0.0.1:5173. Вход: teacher / local-demo-only.

Локальный режим явно помечен в интерфейсе. Он использует предсказуемый тестовый адаптер без Bedrock; данные сохраняются в .local/db.json. На Lambda включить этот режим нельзя.

    npm run check

## Развёртывание AWS

Регион проекта — ap-northeast-1. Используется текущая цепочка AWS credentials; секреты не помещаются в код.

    aws login --profile default
    AWS_PROFILE=default AWS_REGION=ap-northeast-1 npm run deploy

Скрипт проверяет приложение, собирает фронтенд и Lambda, синтезирует CloudFormation через CDK и создаёт/обновляет отдельный стек oc-ai-rpg-demo. Он не меняет CDKToolkit или kotobaflow и не требует их ролей развёртывания.

Приватный bucket oc-ai-rpg-builds-ACCOUNT-ap-northeast-1 хранит ZIP-сборки с сроком 90 дней. Его создание находится вне основного стека, чтобы загружать код до создания Lambda. Скрипт применяет блокировку публичного доступа, шифрование и требование HTTPS. Рабочая Lambda продолжает работать после удаления старого ZIP, но откат к сборкам старше 90 дней потребует повторной загрузки.

Результат развёртывания и имена ресурсов сохраняются в .local/deployment.json; файл не включается в Git.

## Первый учитель

    AWS_PROFILE=default npx tsx scripts/provision-teacher.ts

Скрипт создаёт teacher с временным паролем и сохраняет .local/teacher-access.md с правами 0600. Не отправляет письма. При повторном запуске не меняет существующего пользователя. Чтобы выбрать другой логин, установите TEACHER_USERNAME. Для другого места записи задайте OUTPUT_DIR.

Первый вход попросит сменить временный пароль. Ученикам этот файл не передают. Потерянный пароль сбрасывается администратором в Cognito; самостоятельное восстановление отключено.

## Работа на уроке

- «アプリの設定» — стандартная модель Nova Lite / Haiku 4.5 и переключатель AI.
- Создайте отдельную работу на каждого ученика.
- «生徒に渡す · 60分» — передать текущий компьютер, выйдя из учительского доступа.
- «別の端末用リンク» — одноразовая ссылка для другого компьютера. Неиспользованная ссылка истекает через час.
- «つくる» — редактировать через диалог; «話す» — говорить с персонажем.
- «現在の設定» — посмотреть профиль и вернуть предыдущее изменение.
- Учитель может повторно войти, открыть архив, поменять модель работы и начать новую часовую сессию.

## Бюджет и аварийная пауза

В интерфейсе учителя переключатель AI блокирует новые обращения для его работ. Уже начатый вызов может завершиться.

Месячный AI-бюджет хранится в параметре стека MonthlyBudgetMicroUsd: 10000000 = $10. Скрипт повторного развёртывания сохраняет существующее значение параметра. Для изменения используйте обновление параметров стека CloudFormation. Лимит на сессию задаётся в окружении Lambda и исходниках инфраструктуры. При изменении предпочтителен deploy исходников, чтобы настройки не расходились с кодом.

Бюджет сбрасывается логически с новым календарным месяцем Tokyo; старые записи расходов сохраняются. Не удаляйте записи BUDGET для обхода лимита, если есть выполняющиеся запросы.

## Квота класса

Проверьте:

    aws lambda get-account-settings --region ap-northeast-1
    aws service-quotas list-requested-service-quota-change-history-by-quota --service-code lambda --quota-code L-B99A9384 --region ap-northeast-1

Для 30 одновременных разговоров нужно как минимум 30 свободных запусков Lambda плюс запас на API и остальные проекты. До повышения начальной квоты 10 ожидайте очередь/повтор при допуске запросов; полный класс с 30 одновременными AI-ответами не подтверждён нагрузочным тестом.

## Реальная проверка

    AWS_PROFILE=default AWS_REGION=ap-northeast-1 npx tsx scripts/smoke-lab.ts

Создаёт временного учителя, проверяет первый вход, реальные действия обеих моделей, программу, чат, потоковые ответы через API Gateway, права после передачи и архив выводов после окончания. Выполняет несколько платных Bedrock-запросов. Результаты теста не создаются в архиве обычного teacher.

    AWS_PROFILE=default AWS_REGION=ap-northeast-1 npx tsx scripts/check-models.ts

Более короткая проверка провайдеров, также платная. Она использует credentials запускающего и не проходит через бюджет приложения, поэтому предназначена для диагностики администратора.

## Хранение и удаление

Часовой срок удаляет доступ, а не работу. По умолчанию работы хранятся бессрочно. Учитель может скачать JSON работы со всеми опытами и выводами для резервной копии; ученики не редактируют JSON вручную.

Если проект закрывается: отключите доступ к Lambda, экспортируйте нужные данные, снимите termination protection и удалите стек. Таблицы DynamoDB, Cognito и audio bucket сохранятся по Retain; их и отдельный builds bucket удаляют вручную только после проверки, что данные больше не нужны. Существующие проекты AWS не затрагиваются.

CloudWatch retention — 7 дней. Автоматические резервные копии DynamoDB PITR в этой недорогой демке не включены.

## Собственный домен

Сначала npm run deploy создаёт региональный API Gateway. Затем добавьте CNAME проверки сертификата из DNS.md и выполните:

    AWS_PROFILE=default npx tsx scripts/configure-domain.ts

Команда не ждёт бесконечно неподтверждённый сертификат: возвращает PENDING_VALIDATION и запись DNS. После подтверждения создаёт отдельный стек домена и возвращает настоящий CNAME сайта. Подробные поля お名前.com — в DNS.md. При удалении приложения отдельно учитывайте стек oc-ai-rpg-demo-domain и ACM-сертификат.

Чтобы проверить готовый домен:

    SMOKE_URL=https://ai-taiken.shigorefu.com AWS_PROFILE=default npx tsx scripts/smoke-lab.ts

Проверка создаёт временного преподавателя и делает реальные оплачиваемые вызовы. Не запускайте её многократно без необходимости: защита входа остаётся 10 попыток на IP за 10 минут.
