# Браузерная демка «ことばの街»

Приложение развёртывается в отдельном стеке AWS в Tokyo (ap-northeast-1). Старый Python-проект в source/ и Windows-сборка сохраняются.

## Поток пользователя

1. Учитель входит через форму на сайте. Cognito используется только для учителей; самостоятельная регистрация отключена.
2. Учитель создаёт работу и выбирает Nova Lite или Haiku 4.5. Стандартная модель задаётся в настройках приложения.
3. «生徒に渡す · 60分» заменяет учительскую сессию на ограниченный доступ ученика. Старый cookie учителя немедленно отзывается. Для другого компьютера можно выпустить одноразовый пригласительный URL; час начинается при использовании ссылки.
4. Ученик меняет NPC, героя и историю через чат. Отдельная вкладка позволяет разговаривать с NPC, сохраняя его характер и краткую память.
5. Через час API прекращает доступ. Работа, настройки персонажей, история и расходы остаются в архиве. Повторный вход учителя позволяет просмотреть результат и выдать новый час.

## Компоненты

Browser: React + TypeScript + Phaser
→ HTTPS Lambda Function URL
→ Cognito: проверка учительского пароля
→ DynamoDB Access: непрозрачные сессии, приглашения, защита входа
→ DynamoDB Works: работы, история, версии, модель и использование
→ Amazon Bedrock ConverseStream: Nova Lite / Claude Haiku 4.5
→ private S3: оригинальная музыка по подписанным ссылкам

Lambda также отдаёт HTML, JavaScript и CSS. CloudFront, API Gateway, VPC, NAT Gateway, EC2, ECS и RDS не используются. Нет постоянно работающего игрового сервера: движение персонажей рассчитывает браузер.

## Как чат меняет игру

Для редактора модель получает текущий профиль, мир, героя и до шести последних сообщений выбранного диалога. Ответ содержит текст и предложение изменения только выбранного объекта. Сервер проверяет схему и ограничения, сохраняет предыдущую версию, затем атомарно записывает результат и историю. Только после успешного сохранения браузер применяет новые параметры.

Реализованы пять режимов движения: гулять, стоять, приближаться, отходить, следовать. Скорость, радиус и личная дистанция ограничены. Параметры модели не исполняются как программный код.

В режиме разговора update обязан быть null: NPC может запомнить разговор, но не переписать собственный характер. Отдельно хранится краткая память до 400 символов. «Вернуть предыдущую настройку» восстанавливает предыдущий профиль, сохраняя историю.

Обе модели используют один контракт и серверную валидацию. Нативная компиляция JSON Schema Haiku не используется: реальная проверка показала длительный прогрев и отказ «Schema is too complex» для схемы частичного профиля. Невалидный результат не применяется; допускается одна дополнительная попытка.

## Доступ и сохранность

- Случайный 256-битный токен в Secure / HttpOnly / SameSite=Strict cookie. В базе хранится SHA-256 токена.
- Ученик имеет доступ только к своей работе; выбор модели, создание работ и настройки доступны учителю.
- Каждая изменяющая операция проверяет Origin и CSRF.
- Сервер проверяет expiresAt на каждом запросе и повторно перед сохранением результата AI.
- TTL применяется только к таблице доступа. DynamoDB удаляет такие записи с задержкой; это не влияет на немедленное закрытие API.
- Таблицы работ, доступа, Cognito и аудио имеют Retain при удалении стека; сам стек защищён от удаления.
- CloudWatch хранит технические события и счётчики 7 дней. Тексты диалогов и пароли не пишутся в эти логи.
- Lambda имеет права на две таблицы проекта, его аудио и только выбранные модели Bedrock. AWS-ключи в браузер не передаются.

## Модели

| В интерфейсе     | Bedrock model ID                            |
| ---------------- | ------------------------------------------- |
| Amazon Nova Lite | amazon.nova-lite-v1:0                       |
| Claude Haiku 4.5 | jp.anthropic.claude-haiku-4-5-20251001-v1:0 |

Nova выполняется в Tokyo. Japan-профиль Haiku допускает Tokyo и Osaka. Выбор модели сохраняется в работе; у каждого сообщения остаются фактический modelId, токены, число попыток и оценка стоимости.

## Ограничения расходов

- 60 вызовов модели на одну часовую сессию, включая повтор при невалидном ответе.
- До 1 200 выходных токенов на вызов; ввод ученика до 1 200 символов.
- Одновременно обрабатывается только один AI-запрос на работу.
- $1 на сессию и $10 в календарный месяц по Tokyo для AI всего приложения.
- Перед вызовом атомарно резервируется консервативная максимальная стоимость. Параллельные ученики не могут обойти общий бюджет.
- После ответа резерв заменяется оценкой по фактическим токенам. При неизвестном результате провайдера сохраняется консервативная сумма.
- У запроса есть UUID и постоянная запись результата: повтор того же запроса не вызывает модель ещё раз.
- AWS Budgets не настроен и не является механизмом блокировки. Лимит приложения относится к Bedrock, а не ко всему счёту AWS.

Ограничение бюджета — оценка по заданным тарифам, а не банковская гарантия точной суммы: тарифы AWS, налог и инфраструктура учитываются отдельно.

## Оценка месяца

Допущение: каждый ученик делает 60 вызовов за один урок; в среднем 2 000 входных и 500 выходных токенов на вызов. 30 учеников = 1 800 вызовов.

| Нагрузка                            | Только Nova, AI | Только Haiku, AI |
| ----------------------------------- | --------------: | ---------------: |
| Один урок на 30 учеников в месяц    |           $0.52 |            $8.91 |
| Четыре урока на 30 учеников в месяц |           $2.07 |           $35.64 |

С учётом небольшого запаса на Lambda, DynamoDB, S3, передачу и логи ориентир для одного урока в месяц: около $2–5 с Nova и $10–15 с Haiku. Это не фиксированная подписка; реальные расходы зависят от числа занятий и длины диалогов. Четыре занятия с Haiku потребуют увеличить текущий AI-лимит $10.

Использованные региональные цены на 2026-09-07: Nova $0.072 / $0.288 за миллион входных / выходных токенов; Haiku Japan $1.10 / $5.50.

## Нагрузка класса

На момент первого развёртывания реальная квота Lambda аккаунта — 10 одновременных запусков. Запрос на увеличение отправлен в Service Quotas. До одобрения при одновременных обращениях всего класса возможны задержки. Браузер повторяет только отказы Lambda в допуске запроса (429 до исполнения приложения); сетевые ошибки и отказы бюджета автоматически не повторяются.

Это приложение не создаёт аккаунты AWS ученикам. Для организации нескольких независимых проектов полезен отдельный AWS account, но 30 учеников сами по себе не требуют нового аккаунта.

## Проверки

npm run check выполняет TypeScript, тесты доступа/сессий/бюджета/поведения/инфраструктуры и production-сборку. scripts/smoke-deployed.ts проверяет настоящее HTTPS-приложение с отдельным временным учителем и Bedrock, затем удаляет только собственные тестовые данные, сохраняя учёт потраченного AI.

Браузерная визуальная QA отдельно не проводилась. Экспериментальная WebMCP-интеграция (прочитать текущую работу / выбрать персонажа) включается только при поддержке браузером и не является обязательной для игры; её браузерный контракт отдельно не проверен.
