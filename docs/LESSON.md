# 60分で体験する「プログラム・AI・エージェント」

## 授業のゴール

「AIに指示を出す」「AIの返事を確かめる」「道具を使うエージェント」の違いを、自分の実験結果で説明できるようにします。

## 0〜10分：同じ手順でも、うまくいく？

1. 先生から受け取った体験リンクを開きます。
2. 01「プログラム」、街の状態Aで始め、1ステップずつ進めます。
3. 状態Bに変え、予想を書いてやり直します。
4. どの手順からうまくいかなくなったか、ノートで確認します。

問い：プログラムが悪いのか、それとも想定していない変化が起きたのか？

## 10〜25分：指示と情報を工夫する

1. 02「AIチャット」に切り替えます。「なんとかして。」で相談します。
2. 「落とし物の鍵を持ち主に返すには、最初に何をすればいい？」と具体的に聞きます。
3. 返事と街の状態を比べます。助言をもらうだけで、鍵は返されたでしょうか？
4. 指示に「初心者向けに短く」「質問はひとつずつ」などを加えて、返事を比べます。

問い：AIが「できた」と言ったら、本当にできたと判断してよい？

## 25〜45分：道具を使うエージェント

1. 03「AIエージェント」で具体的な目標を与えます。
2. 街の状態B、記憶ON、道具をすべて許可して試します。
3. 各ステップの「渡した情報」「選んだ行動」「ゲームの結果」を見ます。
4. 「周りを見る」を禁止する、または記憶をOFFにして再実験します。
5. 必要なら停止します。ひとつの実験は最大12ステップです。

問い：同じAIでも、道具や記憶が変わると結果はどう変わる？

## 45〜60分：NovaとHaikuを比べ、説明する

1. 目標・街の状態・記憶・道具をそろえてモデルだけ変更します。
2. 成功だけでなく、行動数、無駄な操作、説明、AI利用量を比較します。
3. 「予想」「実際の結果」「そうなった理由」を気づきに書いて保存します。
4. 友達の結果と比較します。1回で違いを言い切らないようにします。

## 覚えておきたいこと

- 指示を変えることは、この授業ではモデルの再学習ではありません。
- 記憶はアプリが過去の情報を渡して実現しています。
- AIが見えるのはアプリから渡された情報です。人が見ている画面の全部を知っているわけではありません。
- エージェントはAIが道具を選び、アプリが実行し、結果を次の判断に渡す仕組みです。
- 成功はAIの発言ではなく、ゲーム内で鍵が本当に返されたかで確認します。
- 体験終了後も実験と気づきは保存され、先生が確認できます。

先生へ：1時間の上限はAI呼び出し60回。プログラムの実験ではAIを使いません。曖昧な指示や失敗も学習材料なので、成功だけを評価しない構成にしてください。
